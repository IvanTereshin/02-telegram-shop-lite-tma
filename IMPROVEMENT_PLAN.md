# Improvement plan: Telegram Shop Lite TMA

Основано на `CUSTOMER_REVIEW.md`. Цель - сделать магазин похожим на реальную витрину бренда, а не на универсальный каталог товаров.

## Целевое направление

Ниша: specialty coffee and home goods.  
Визуальный стиль: milk, graphite, roasted brown, muted copper, крупные товарные фото.  
Главное ощущение: пользователь понимает бренд, доверяет доставке и быстро доходит до покупки.

## GSAP-анимации

Добавить зависимости:

```bash
npm install gsap @gsap/react
```

Где применить:

- Product grid reveal: товары появляются stagger-анимацией при смене категории или сортировки.
- Featured product: фото слегка увеличивается на входе, но не loop-анимацией.
- Add to cart: товарная карточка коротко реагирует `scale: 0.98 -> 1`, cart CTA обновляется с count-bounce.
- Product drawer: открытие снизу через `yPercent` и затемнение overlay через `opacity`.
- Checkout steps: активный шаг плавно сдвигает progress indicator.
- Order tracking: статусы заказа появляются как timeline с последовательным reveal.

Ограничения:

- Не анимировать цену слишком долго. Цена должна быть стабильной.
- Не делать flying-cart через весь экран, это будет выглядеть дешево.
- Учитывать `prefers-reduced-motion`.

## Критерии готовности

- Магазин считывается как конкретный бренд.
- Каталог не выглядит сеткой одинаковых карточек.
- Checkout понятен и вызывает доверие.
- Статус заказа объясняет, что происходит после покупки.
- GSAP усиливает покупательский flow, а не отвлекает от товара.
